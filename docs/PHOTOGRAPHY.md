# 逐光中南 v19：光影重拍图集

这是一组从现有 v19 模型重新拍摄的展示图片。摄影布光、相机取景、构件显示隔离与爆炸位置只在临时内存场景中调整；没有保存或重新导出源模型，也没有修改原 v19 目录已有的图片。

## 本轮图集

- `拆解爆炸图_v19_光影双栏.png`：分左右两栏展示九组构件，采用独立摄影棚布光与清晰层间阴影；同一栏中保持构件相对比例，左右两栏的摄影比例可不同。
- `分解大图/01_…png` 至 `09_…png`：校门、园景、台面、上壳、LED 灯板、控制主板、托架、旋转底座、底盖九张独立大图。每组按自己的包围盒取景；底盖采用独立上方斜视角展示外形轮廓。
- `整体效果图_光影版.png`、`正视图_光影版.png`、`背面效果图_光影版.png`、`侧视图_光影版.png`、`俯视图_光影版.png`：本版整机的摄影效果与多个观察方向。
- `复刻校门雕刻特写_光影版.png`：当前 v19 复刻校门的雕刻细部近景。
- `电子结构装配_光影版.png`、`灯光控制主板特写_光影版.png`、`环形LED灯板特写_光影版.png`、`固定线束接口_光影版.png`：电子总成、板件、灯板和固定连接路径的摄影展示。
- `九组构件_光影放大总览.png`：九张独立构件图的总览，便于在同一版面查看细节。
- `左侧校训_光影版.png`、`右侧校训_光影版.png`：两侧校训及对应浅浮雕的近景。
- `背面矿业湘雅_光影版.png`：背面矿业、湘雅图章的细节。
- `360度刻度_光影版.png`：完整计时刻度和火车头指针的近景。

独立构件图的取景倍率不同，不能根据图上显示大小直接比较实物尺寸；爆炸图只移动整组的展示位置，不改变组内构件形态。图集没有把校门、主板或其他构件缩放后写回源模型。模型的实际尺寸与装配状态仍以原 `逐光中南_v19.blend` 为准。

## 光影与隔离

拍摄使用临时的柔光主灯、补光、轮廓灯和顶灯，围绕当前被摄构件重新定位，避免高处爆炸层照不到灯。只启用目标组的可渲染构件，同时处理网格、曲线和文字，减少原图中无关底座、刻度与悬空线束的残影。线束在电子总成和线路接口图中显示，在总爆炸图及其他独立构件图中隐藏。

## 源文件只读校验

以下四个源文件始终位于原 v19 目录，图集不包含它们：

- `逐光中南_v19.blend`
- `逐光中南_v19.glb`
- `逐光中南_v19.obj`
- `逐光中南_v19.mtl`

`源文件只读校验_开始.json` 保存拍摄前的 SHA256、字节数和纳秒修改时间。打包脚本会逐一复核三项数值，全部一致才生成图集 ZIP；结果写入 `源文件只读校验_完成.json`。打包后还会再次复查源文件，确认打包过程没有改写源模型。

`拍摄数据_parts.json`、`拍摄数据_views.json`、`拍摄数据_electronics.json` 记录每张图的分组、隔离对象、取景范围与源文件哈希；`爆炸图拍摄数据.json` 记录九组爆炸位置与双栏布局。若附有预览拍摄数据，它仅用于过程核对；预览图片和渲染缓存不在正式图集内。

## 文件包

`v19_光影重拍图集.zip` 只包含本文件夹中新输出的正式 PNG、`分解大图` 子目录、拍摄数据及只读校验说明。原目录的旧图、预览图片、渲染缓存和四个源建模文件均不打包。该图集用于外观和结构展示；电子件仍是原模型的三维装配示意，不代表已完成生产用电路设计。
